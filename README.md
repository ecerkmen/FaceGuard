# FaceGuard
**A real-time facial recognition doorbell that alerts you on Telegram.**

FaceGuard is a real-time facial recognition security system that sends Telegram notifications when any face other than the designated owner is detected at the door. It captures face data for registered individuals, trains a Support Vector Machine (SVM) classifier on 128-dimensional facial encodings generated by dlib, and runs continuous live inference through a webcam feed. Detections are classified either as a known registered individual or as an unknown person, and each triggers a Telegram alert containing both a text message and a photo.

Built with Python · OpenCV · dlib / face_recognition · scikit-learn · python-telegram-bot

---

## How it works

FaceGuard is three scripts, run in order:

1. **`collect.py`** — opens the webcam and saves photos of one person into a folder named after them (30 photos per person).
2. **`train.py`** — turns every photo into a 128-dimensional face encoding with dlib and trains an SVM classifier on these encodings, saved as `model.pkl`.
3. **`recognise.py`** — watches the webcam feed, recognises faces, and sends the Telegram alerts.

Inside `recognise.py`, no single frame decides who is at the door:

- **Detection:** faces are detected on a copy of each frame shrunk to a quarter of its size, which keeps the live feed fast.
- **Classification:** the SVM predicts a name for each face. If its confidence is below 80%, the face is labelled `Unknown person`.
- **Tracking:** each face is compared with the faces already being followed, using the Euclidean distance between their encodings (a distance under 0.6 counts as the same person). This way the same person keeps the same ID from frame to frame.
- **Buffering:** for each tracked face, one frame per second is saved, together with its predicted name, confidence and a blur score (the variance of the Laplacian; the higher, the sharper).
- **Voting:** after 10 frames, the 5 blurriest are discarded, and the name that appears most often among the 5 sharpest is the final decision.
- **Alert:** if the final name is not the owner's, FaceGuard sends a Telegram message (`<name> is at the door.`) and the sharpest of the frames as a photo.

## Installation

**1. Clone the repository**

```
git clone https://github.com/ecerkmen/FaceGuard.git
cd FaceGuard
```

**2. Install the required libraries**

```
pip install opencv-python face_recognition scikit-learn python-telegram-bot python-dotenv
```

> `face_recognition` is built on dlib, which is compiled during installation. If the installation fails, install CMake and a C++ compiler first (on Windows: Visual Studio Build Tools with the "Desktop development with C++" workload), then try again.

**3. Create a Telegram bot**

- In Telegram, open a chat with **@BotFather**, send `/newbot` and follow the steps. BotFather gives you a **token**.
- Send any message to your new bot, then open `https://api.telegram.org/bot<your-token>/getUpdates` in your browser. Your **chat ID** is the number after `"chat":{"id":`.

**4. Create a `.env` file** in the FaceGuard folder with these two lines:

```
TELEGRAM_TOKEN=your-bot-token
TELEGRAM_CHAT_ID=your-chat-id
```

The `.env` file is excluded from git, so your token is never uploaded.

**5. Set the owner's name**

In `recognise.py`, find the line `if freq_name != "Ece":` and replace `Ece` with your own name, spelled exactly like your folder name in the next step. FaceGuard alerts you about everyone except this person.

## How to use

### Step 1 — Collect photos

```
python collect.py
```

Type the person's name and press Enter. A webcam window opens: press **Space** to save a photo. The script stops automatically after 30 photos (or press **q** to stop earlier). Vary the angle, expression and lighting a little between photos.

Repeat for every person you want to register, starting with yourself.

The photos are saved in a folder named after the person, inside the folder you ran the script from. `train.py` looks for these folders in a folder called **`dataset` on your Desktop**, so move each person's folder there:

```
Desktop/
└── dataset/
    ├── Ece/
    ├── Zeynep/
    └── ...
```

### Step 2 — Train the classifier

```
python train.py
```

The script prints how many face encodings it found and saves the trained classifier as `model.pkl`. Photos in which no face could be found are skipped.

Run `train.py` again whenever you add a new person.

### Step 3 — Start FaceGuard

```
python recognise.py
```

Run it from the same folder as `model.pkl`. A window shows the webcam feed with a box and a name on every face. Press **q** to stop.

---

## Important notes

- A decision takes about 10 seconds of a face being in view, since FaceGuard collects one frame per second and votes over 10 of them.
- While someone other than the owner stays in view, a new alert is sent about every 10 seconds.
- The photo in the alert is the whole webcam frame (with the box and name FaceGuard draws on it), not a crop of the face.
- Photos, `model.pkl` and `.env` stay on your computer: they are excluded from git. The only data that leaves your computer is the Telegram alert.
- The SVM needs at least two registered people to train.
